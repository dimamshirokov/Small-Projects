## ❄️ Description

[Data](https://www.kaggle.com/datasets/romaneyvazov/penguins-lter) were collected and provided by Christina Gorman and Palmer Station, located on Anvers Island, north of the Antarctic Circle.

For more details, see the following work in English: Gorman KB, Williams TD, Fraser WR (2014) Ecological Sexual Dimorphism and Environmental Variability within a Community of Antarctic Penguins (Genus Pygoscelis).

### 🏝️ Features

- **culmen_length_mm**: Beak length (mm);
- **culmen_depth_mm**: Beak height (mm);
- **flipper_length_mm**: Wing length (mm);
- **body_mass_g**: Body weight (g);
- **island**: Island name (Dream, Torgersen, or Biscoe) in the Palmer Islands (Antarctica);
- **sex**: Penguin's sex.

### 🧬 Target Feature

- **species** (target): penguin species - chinstrap penguin, adélie penguin, or gentoo penguin;
