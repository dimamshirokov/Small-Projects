## 📋 Description

This is a desktop application that allows you to plot functions from one variable over a given period. 
You can also save the image of this graph in .png format.

## 🏋🏼‍♀️ Requirements

- tkinter
- numpy
- matplotlib

## 🧩 Run the program

While in the folder /Small-Projects/Graph-Plotter, run the command below.

```console
pip install -r requirements.txt
```

Meanwhile, in the folder /Small-Projects/Graph-Plotter/src, run the command below.

```console
python3 main.py
```
