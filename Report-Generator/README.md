# Report Generator

## :newspaper: Description

This is a console application that accepts a CSV or JSON file as input and adds a table from it to a PDF file. It is also possible to add a line chart, a bar chart, and a pie chart to a PDF. That is, it is an application for generating PDF reports.

## :computer: Requirements

- fpdf2
- io
- matplotlib
- pandas

## :slot_machine: Run the program

```console
python3 application.py
```
